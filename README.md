# Plant Disease Classifier

Проект в области компьютерного зрения (Computer Vision) для автоматического распознавания заболеваний листьев сельскохозяйственных культур по фотографиям. 

Включает в себя сверточную нейронную сеть (CNN), обученную с нуля, и графическое desktop-приложение для тестирования модели на пользовательских изображениях.

## Особенности проекта

* Кастомная архитектура CNN: Модель построена с использованием PyTorch. Включает 3 сверточных блока (Conv2d + MaxPool2d + ReLU) и полносвязные слои (Linear).
* Широкий охват (38 классов): Модель способна различать заболевания и здоровые состояния множества видов растений (яблоня, вишня, кукуруза, виноград, персик, перец, картофель, томат и др.).
* Высокая точность: Модель демонстрирует высокую точность распознавания (Accuracy ~97%) на тестовой выборке датасета New Plant Diseases Dataset.
* Графический интерфейс (GUI): Приложение на базе Tkinter позволяет легко загружать изображения в форматах .jpg, .jpeg, .png, автоматически применяет необходимые трансформации (Resize 256x256, Normalize) и выводит отформатированный результат на экран.

## Установка и запуск

### Требования
Для работы приложения необходим Python 3.8+ и установленные зависимости.

### Склонируйте репозиторий:
    git clone https://github.com/yourusername/plant-disease-classifier.git
    cd plant-disease-classifier

### Установите необходимые библиотеки:

    pip install torch torchvision pillow numpy

(Примечание: для запуска готового приложения дискретная видеокарта не обязательна, инференс модели настроен на работу с CPU).

### Скачайте веса модели:

Необходимо загрузить веса модели и поместить в папку проекта: https://drive.google.com/file/d/1Zx4DuTu85LaFdquXMZJ_xPdSP0MrjIkJ/view?usp=sharing

### Запуск приложения

Запустите графический интерфейс командой:

    python app.py

В открывшемся окне:

    Нажмите "Загрузить изображение" и выберите фото листа растения.

    Нажмите "Распознать".

    Модель обработает изображение и выведет предсказанный диагноз.

## Датасет и обучение

Модель обучалась на открытом наборе данных New Plant Diseases Dataset (Augmented).
Обучение реализовано батчами по 4 изображения с использованием функции потерь CrossEntropyLoss и оптимизатора SGD (Stochastic Gradient Descent) со скоростью обучения lr=0.01. Входные изображения нормализуются и приводятся к размеру 256x256 пикселей.

Для самостоятельного запуска процесса обучения скачайте датасет, укажите пути к тренировочной и валидационной выборкам в файле train.py и выполните скрипт.
